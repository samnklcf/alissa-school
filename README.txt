ALISSA SCHOOL — PAGE D'ACCUEIL (projet complet)
================================================

Contenu :
  index.html   → la page d'accueil complète (HTML + CSS + JS, sans React)
  logo.png     → le logo Alissa School
  assets/      → les 17 images (maquettes, partenaires, avatars, etc.)

Mise en ligne :
  Déposez index.html, logo.png et le dossier assets/ à la racine de votre
  site (schools.alissa-ia.ga). Les chemins sont déjà relatifs (/assets/...,
  /logo.png), exactement comme sur la page d'origine.

À personnaliser :
  1. Vidéo de démonstration : dans index.html, remplacez
     REMPLACER_PAR_ID_YOUTUBE par l'ID de votre vidéo YouTube
     (une seule occurrence, dans le script en bas de page).
  2. Liens réseaux sociaux et mentions légales : href="#" dans le footer,
     à remplacer par vos vraies URLs quand vous les avez.

Liens conservés à l'identique :
  - Boutons d'essai : https://app.alissa-ia.ga/install
  - Boutons fonctionnalités : https://app.alissa-ia.ga/install/install
  - Pour les écoles : /institutionnel (page à créer ensuite)
  - SEO, Open Graph, JSON-LD et analytics : inchangés.

Couleurs principales : #7522A5 (violet) et #F5C800 (jaune).
